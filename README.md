# hermes-skill-brain-summary

Скилл [Hermes Agent](https://hermes-agent.nousresearch.com/docs) с двумя режимами:

- **Саммари** — «краткое содержание» / «саммари» / «перескажи» + любой контент (медиа, статья, файл, тема): контент преобразуется в текст (медиа — тот же пайплайн yt-dlp + mlx-whisper) и возвращается короткое резюме одним сообщением в Telegram. В Brain ничего не сохраняется.
- **Полный** — «добавь в мозг» / «добавь в brain» / «+мозг» + что добавить, ИЛИ голая ссылка на YouTube без слов вокруг: архивация любого контента в базу знаний `~/gdrive/Brain/` (медиа — yt-dlp + mlx-whisper; статьи и страницы — tavily extract; темы без ссылки — поиск → лучший источник; файлы; готовый текст), коррекция транскрипта, подробный `_sum.md` и синк векторной базы. Сказанное после саммари («добавь это в мозг») довыполняет архивацию поверх уже готового текста, без повторной транскрибации.

Ссылка НЕ на YouTube без команды скилл не запускает — только через явную команду («добавь в мозг/brain» или «краткое содержание/саммари»).

Это **оркестратор** над двумя другими скиллами, порядок строгий:

1. [`media/yt-dlp`](https://github.com/vokasug/hermes-skill-yt-dlp) — метаданные + скачивание аудио в `~/result-yt-dlp/`
2. [`media/mlx-whisper`](https://github.com/vokasug/hermes-skill-mlx-whisper) — локальная транскрибация (MLX Whisper + Silero VAD) в `~/result-mlx-whisper/`: только распознавание речи, один MD-файл

## Что делает

- **Метаданные до скачивания** — заголовок, автор, длительность, описание через `yt-dlp --skip-download --print`
- **Гейт языка** — язык определяется из заголовка/описания (или детектом на первых 30 с) ДО запуска транскрибации; источник языка называется явно. Дефолт «ru по привычке» запрещён — главный pitfall скилла
- **Коррекция транскрипта агентом (только полный режим)** — после копирования MD в папку Brain агент читает субтитры контента (если скачались — «второе мнение» поверх транскрипта) и использует заголовок/описание как источник канонических написаний терминов; правит копию точечно (patch), только ослышки и написание терминов; числа всегда остаются из транскрипта — субтитры в числах ошибаются; веб-поиск для коррекции не используется
- **Субтитры — всегда пытаться скачать** (`--write-subs --write-auto-subs`); идут в коррекцию как второй ASR-текст, заметно чинит ослышки имён/терминов
- **Ссылка — один раз, в блоке метаданных в конце и в `code`-формате** — любая кликабельная ссылка в сообщении даёт embed-превью сайта; первая строка ответа — название видео, автор, длительность, язык
- **Пересказ по смысловым блокам** — короткие абзацы/список без таймкодов; таймкоды — только в ответах на доп. вопросы (цитаты из транскрипта)
- **Честность по распознаванию** — если имена/термины в транскрипте ненадёжны, это сказано прямо с указанием затронутых фрагментов
- **Переиспользование артефактов** — mp3 и MD остаются на диске; доп. вопросы по видео позже отвечаются по сохранённому транскрипту без повторной транскрибации
- **Архивация в базу знаний (только полный режим)** — MD транскрипта копируется в предметную папку `~/gdrive/Brain/` (выбор по правилам `Brain/AGENTS.md`) и там корректируется, рядом сохраняется подробный пересказ `YYYY-MM-DD_<имя>_sum.md` (до 16000 символов, та же структура «Главная мысль / Ключевые тезисы / Вывод» + блок метаданных); в ответе пользователю — блок с метаданными и названием папки Brain
- **Дефолт автора для Plaud** — если источник метаданных не определяется, автор по умолчанию `unknown`, но для записей/конспектов Plaud (маркеры «note 1/1», «auto_sum_note», «consumer_note», «Meeting Minutes») — `plaud`

## Связанные скиллы

- [`brain-vector`](https://github.com/vokasug/hermes-skill-brain-vector) — векторная база поверх `*_sum.md`: семантический поиск по вопросам к мозгу с фильтрами по папке/автору/дате. Пополнение — кроном каждые 4 часа (инкрементально), оптимизация — ежедневно в 06:00. Новый sum-файл из этого скилла синхронизируется сразу, крон остаётся страховкой.

## Установка на чистый Mac

### 1. Зависимости — оба скилла-компонента

Ставятся вместе со своими зависимостями (ffmpeg, node, uv-инструмент mlx-whisper, модели whisper):

```bash
git clone https://github.com/vokasug/hermes-skill-yt-dlp $HERMES_HOME/skills/media/yt-dlp
git clone https://github.com/vokasug/hermes-skill-mlx-whisper $HERMES_HOME/skills/media/mlx-whisper
```

### 2. Этот скилл

```bash
git clone https://github.com/vokasug/hermes-skill-brain-summary $HERMES_HOME/skills/brain-summary
```

Hermes подхватывает скилл автоматически; проверить: `hermes skills list`.

### 3. Проверка

```bash
# метаданные должны вернуться без скачивания
~/.local/bin/yt-dlp --js-runtimes node --skip-download \
  --print "%(title)s | %(duration)s сек" "https://www.youtube.com/watch?v=VIDEO_ID"
```

Затем в Hermes: «о чём это видео? <ссылка>» — скилл сработает по триггеру.

## Использование

Пайплайн выполняет агент по SKILL.md этого скилла, вызывая скиллы-компоненты через их
собственные инструкции (`skill_view media/yt-dlp`, `skill_view media/mlx-whisper`,
`skill_view brain-vector`) — чужие скрипты напрямую не вызываются, команды и пути к
ним живут только в SKILL.md соответствующего скилла:

1. метаданные + детект языка — сырым `~/.local/bin/yt-dlp` (установленный CLI, не скрипт скилла);
2. аудио в `~/result-yt-dlp/` — по процедуре скилла yt-dlp (`download_dated.py --audio`);
3. субтитры (если есть) — сырым yt-dlp;
4. транскрибация в `~/result-mlx-whisper/` — по Quick Reference скилла mlx-whisper
   (`--language` из шага 1, `--meta-*` для шапки MD); скрипт только распознаёт речь
   и пишет один MD-файл;
5. пересказ в Telegram; в полном режиме — копия MD в `~/gdrive/Brain/`, её коррекция
   агентом (patch, по субтитрам и метаданным; числа не трогаем), `_sum.md` и синк
   векторной базы по процедуре скилла brain-vector.

## Настройка под себя

Скриптовая часть — только `scripts/html2md.py` (конвертер HTML→MD для не-медиа ветки). Пути `~/result-yt-dlp` / `~/result-mlx-whisper` и расположение моделей наследуются от скиллов-компонентов; на своём Mac настройте их по README тех репозиториев. Внешние API и ключи для коррекции не нужны — её выполняет основная модель агента.
